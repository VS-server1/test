# 1. Запуск сайта

Разместить папку сайта office_shop в htdocs установленного XAMPP (например, ``C:\xampp\htdocs\office_shop`` или ``D:\xampp\htdocs``). Найдите также ``xampp-control.exe`` и там включите Apache и MySQL. 
Выполнить database.sql в phpMyAdmin; файл создаёт базу office_shop_45, таблицу products и три исходные записи.

## Создать БД

<img width="1348" height="653" alt="image" src="https://github.com/user-attachments/assets/84e04aad-bd5a-43ad-a340-662d468f30f1" />

После этого заходим в раздел SQL, и отправляем содержимое ``database.sql`` :

```bash
-- Отдельная учебная база. Исходную базу ранее изученного сайта изменять не требуется.
-- Скрипт не удаляет базы, таблицы или записи. Повторный импорт не сбрасывает решения.
CREATE DATABASE IF NOT EXISTS office_shop_45
    CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE office_shop_45;

CREATE TABLE IF NOT EXISTS products (
    id INT UNSIGNED NOT NULL AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(120) NOT NULL,
    price INT UNSIGNED NOT NULL,
    quantity INT UNSIGNED NOT NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- В этой работе цена указывается целым числом рублей.
INSERT IGNORE INTO products (id, name, price, quantity)
VALUES (1, 'Принтер «Офис-П20»', 18000, 3);
INSERT IGNORE INTO products (id, name, price, quantity)
VALUES (2, 'Монитор «Офис-М24»', 12000, 4);
INSERT IGNORE INTO products (id, name, price, quantity)
VALUES (3, 'Сканер «Офис-С10»', 9000, 2);

-- Товар с id = 4 отсутствует намеренно. Его добавляет студент по условию задания.
```

Прокрутите вниз и нажмиите на кнопку вперед(вы запустите код). После этого заходим в БД/products:

# 3.  Карточка товара на PHP

Доработайте блок данных карточки в файле office_shop/index.php. На странице должны отображаться название, цена и остаток нового товара, полученные из базы данных, а не записанные вручную в PHP.
Добавьте определение наличия по остатку: если количество больше 0 — «В наличии», если равно 0 — «Нет в наличии». Данные карточки должны обновляться при перезагрузке страницы.

**Решение:**

Зайти в index.php и найдите раздел:

```php
if ($product) {
    $name = 'Название товара пока не выведено';
    $price = 0;
    $stock = 0;

    // Подготовьте информацию о наличии товара.
}
// Конец блока данных карточки товара. Ниже расположена готовая разметка.
```

**Замените на:**

```php
if ($product) {
    $name = $product['name'];
    $price = (int) $product['price'];
    $stock = (int) $product['quantity'];

    if ($stock > 0) {
        $status = 'В наличии';
    } else {
        $status = 'Нет в наличии';
    }
}
```
