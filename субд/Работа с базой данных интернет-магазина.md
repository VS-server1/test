# 2 Этап - Решение задач 

## 1. Рабочая таблица. 
Создайте схему processing_practice и таблицу products_work. Скопируйте в неё данные всех товаров из public.products по указанным полям. Предусмотрите заданные ограничения.

|Поле|	Тип данных|	Требование|
|---|---|---|
|product_id|	INTEGER|	Первичный ключ|
|product_name|	VARCHAR(100)| Обязательное значение|
|category_id|	INTEGER|	—|
|unit_price|	NUMERIC(10,2)|	Цена не ниже 0|
|discontinued|	INTEGER|	—|

```bash
-- 1
CREATE SCHEMA processing_practice;

CREATE TABLE processing_practice.products_work (
    product_id     INTEGER PRIMARY KEY,
    product_name   VARCHAR(100) NOT NULL,
    category_id    INTEGER,
    unit_price     NUMERIC(10,2) CHECK (unit_price >= 0),
    discontinued   INTEGER
);

INSERT INTO processing_practice.products_work
    (product_id, product_name, category_id, unit_price, discontinued)
SELECT product_id, product_name, category_id, unit_price, discontinued
FROM public.products;
```
> Проверка: в рабочую таблицу скопированы товары из public.products. Первичный ключ запрещает дубли product_id; NOT NULL запрещает пустое название, CHECK запрещает отрицательную цену. 

## 2. Выборка с соединением таблиц. 
Получите список товаров категории category_id = 1, не снятых с продажи (discontinued = 0). Выведите название товара (product_name), название категории (category_name) и цену (unit_price). Отсортируйте товары по возрастанию цены.

```bash
-- 2
SELECT p.product_name,
       c.category_name,
       p.unit_price
FROM processing_practice.products_work AS p
JOIN public.categories AS c
    ON p.category_id = c.category_id
WHERE p.category_id = 1
  AND p.discontinued = 0
ORDER BY p.unit_price ASC;
```
> Результат: товары категории 1, не снятые с продажи, и название категории; сначала показываются товары с меньшей ценой.

## 3. Добавление, изменение и проверка ограничения. 
Добавьте товар с данными: product_id = 1000; product_name = «Учебный товар»; category_id = 1; unit_price = 10.00; discontinued = 0. Измените его цену на 12.00 и выведите данные товара. Затем отдельной командой попытайтесь изменить цену на −1: операция должна завершиться ошибкой, а цена остаться 12.00.

```bash
-- 3
INSERT INTO processing_practice.products_work
    (product_id, product_name, category_id, unit_price, discontinued)
VALUES (1000, 'Учебный товар', 1, 10.00, 0);

UPDATE processing_practice.products_work
SET unit_price = 12.00
WHERE product_id = 1000;

SELECT product_id, product_name, unit_price
FROM processing_practice.products_work
WHERE product_id = 1000;
```

> **1 Ожидаемый результат:** одна строка: 1000 | Учебный товар | 12.00.

Отдельно выполните следующую команду (ошибка здесь ожидаема):

```bash
-- проверка 1
UPDATE processing_practice.products_work
SET unit_price = -1
WHERE product_id = 1000;
```

> **2 Ожидаемый результат:** PostgreSQL отклонит UPDATE, так как нарушено условие CHECK (unit_price >= 0).

Проверьте, что после отклонённой команды цена осталась прежней:

```bash
-- проверка 2
SELECT product_id, unit_price
FROM processing_practice.products_work
WHERE product_id = 1000;
```

> **3 Ожидаемый результат:** 1000 | 12.00. При запуске внутри явной транзакции после ошибки сначала требуется ROLLBACK; без явной транзакции в обычном режиме pgAdmin следующую команду можно запускать отдельно.

## 4. Изменение статуса и удаление. 
Для учебного товара установите discontinued = 1. Убедитесь, что он больше не попадает в выборку пункта 2. Удалите товар с product_id = 1000 и определите, сколько строк осталось в products_work.

```bash
-- 4
UPDATE processing_practice.products_work
SET discontinued = 1
WHERE product_id = 1000;
```

**Проверка:** снова выполните запрос пункта 2. «Учебный товар» в списке не появится, поскольку discontinued = 1.

```bash
-- проверка 1
DELETE FROM processing_practice.products_work
WHERE product_id = 1000;

SELECT COUNT(*) AS products_count
FROM processing_practice.products_work;

SELECT COUNT(*) AS source_count
FROM public.products;
```

> **Ожидаемый результат:** оба значения COUNT(*) совпадут, если в исходных данных нет товара с product_id = 1000. Само количество строк зависит от версии Northwind.
